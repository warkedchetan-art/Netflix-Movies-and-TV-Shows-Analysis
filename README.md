# 🎬 Netflix Movies and TV Shows Data Analysis

## 📌 Project Overview

This project is based on Netflix Movies and TV Shows data analysis using Python.

The main objective of this project is to explore Netflix content, analyze Movies and TV Shows, understand content ratings, and identify the top countries contributing content to Netflix.

In this project, I used Pandas for data cleaning and data analysis and Matplotlib for data visualization.

## 🎯 Project Objectives

- Analyze Movies and TV Shows distribution.
- Identify the most common content ratings.
- Find the top 10 countries with the highest Netflix content.
- Analyze year-wise content addition.
- Understand Netflix content distribution.
- Explore different categories of Netflix content.

## 📂 Dataset Information

Dataset: Netflix Movies and TV Shows

Total Records: 8,809

Dataset Format: CSV

Important Columns:
- show_id
- type
- title
- director
- cast
- country
- date_added
- release_year
- rating
- duration
- listed_in
- description

## 💡 Key Insights

- The dataset contains 8,809 Netflix titles.
- The United States has the highest number of titles.
- India is among the top countries producing Netflix content.
- TV-MA is the most common content rating.
- 2019 had the highest number of titles added to Netflix.
